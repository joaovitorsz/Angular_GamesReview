# Games Review

O **Games Review** é uma plataforma web responsiva feita de gamers para gamers, permitindo que a comunidade registre e compartilhe avaliações dos seus jogos favoritos.

## ✨ Funcionalidades
* **Design Responsivo:** Layout fluido e adaptável para monitores e celulares, construído a partir de CSS Grid.
* **Dark Mode Elegante:** Interface imersiva utilizando variáveis CSS para uma paleta de cores escuras com contrastes em tons areia e dourado.
* **Formulário Dinâmico:** Criação de novas avaliações com validação de campos vazios, feedback visual de erro/sucesso nativo, e formatação inteligente de texto no TypeScript.
* **Galeria Interativa:** Painel de avaliações com animações suaves de entrada, efeitos de hover e expansão de detalhes via class binding.

## 🛠️ Tecnologias Utilizadas
* Angular (CLI 22.2.1)
* HTML5
* CSS3 (Grid Layout, Variáveis Nativas, Keyframes)
* TypeScript

## 🚀 Como executar o projeto localmente

Para iniciar o servidor de desenvolvimento, rode o comando abaixo no terminal:

```bash
ng serve
```

Assim que o servidor estiver no ar, abra o navegador e acesse `http://localhost:4200/`. A aplicação vai recarregar automaticamente sempre que você salvar alguma alteração no código.
